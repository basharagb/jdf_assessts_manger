# نظام إدارة أصول الأسواق الحرة الأردنية

تطبيق Laravel باللغة العربية لإدارة أسواق الشمال والوسط والجنوب، وتسجيل بيانات السوق وعقد الإيجار، وحساب الإجمالي الشهري لفترة يحددها المستخدم.

## المتطلبات

- PHP 8.3 أو أحدث مع إضافات PDO MySQL وFileinfo وMbstring
- Composer
- MySQL
- Node.js غير مطلوب لتشغيل الواجهة؛ ملفات التنسيق مرفقة داخل `public/css/app.css`

## الإعداد

أنشئ قاعدة البيانات `jdf_assets` في MySQL، ثم راجع إعدادات الاتصال في `.env` إذا كان اسم المستخدم أو كلمة المرور مختلفاً عن الإعداد المحلي الافتراضي.

```bash
composer install
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan app:create-admin
php artisan serve
```

افتح `http://127.0.0.1:8000` وسجّل الدخول بالبريد وكلمة المرور اللذين أدخلتهما عند تشغيل `app:create-admin`.

## ميزات النظام

- لوحة تحكم تعرض إجمالي الأسواق، الأسواق النشطة، الإيجار الشهري، والعقود التي تنتهي خلال 90 يوماً.
- صفحات منفصلة لأسواق الشمال والوسط والجنوب، مع عرض الأسواق كبطاقات قابلة للفتح.
- إضافة سوق وتعديله وأرشفته أو حذفه، مع صورة ومساحة وجهة مؤجرة وملاحظات.
- حفظ الإيجار الشهري وتاريخ بداية العقد ونهايته الاختياري.
- حاسبة فترة شهرية شاملة: تختار شهري البداية والنهاية، فيحسب النظام الإيجار الشهري مضروباً بعدد الأشهر المتداخلة مع العقد، ويستبعد ما يقع خارج مدته.
- بحث باسم السوق أو الجهة المؤجرة، وفلترة بحسب المنطقة.
- تسجيل دخول محمي، وإنشاء حساب المدير من سطر الأوامر من دون كلمة مرور افتراضية مزروعة.
