# الشؤون الادارية- توثيق وترخيص ممتلكات

تطبيق Laravel باللغة العربية لإدارة أسواق الشمال والوسط والجنوب، وتسجيل بيانات السوق وعقد الإيجار، وحساب الإجمالي السنوي لفترة يحددها المستخدم.

## المتطلبات

- PHP 8.3 أو أحدث مع إضافات PDO MySQL وFileinfo وMbstring وGD وDOM
- Composer
- MySQL
- Node.js 20 أو أحدث لتشغيل خدمة واتساب ويب وبناء ملفات الواجهة؛ ملفات التنسيق مرفقة داخل `public/css/app.css`

## الإعداد

أنشئ قاعدة البيانات `jdf_assets` في MySQL، ثم راجع إعدادات الاتصال في `.env` إذا كان اسم المستخدم أو كلمة المرور مختلفاً عن الإعداد المحلي الافتراضي.

```bash
composer install
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan app:create-admin
php artisan serve
```

افتح `http://127.0.0.1:8000` وسجّل الدخول بالبريد وكلمة المرور اللذين أدخلتهما عند تشغيل `app:create-admin`.

## ميزات النظام

- لوحة تحكم تعرض إجمالي الأسواق، الأسواق النشطة، الإيجار السنوي، والعقود التي تنتهي خلال 90 يوماً.
- صفحات منفصلة لأسواق الشمال والوسط والجنوب، مع عرض الأسواق كبطاقات قابلة للفتح.
- إضافة سوق وتعديله وأرشفته أو حذفه، مع صورة ومساحة وجهة مؤجرة وملاحظات.
- حفظ الإيجار السنوي وتاريخ بداية العقد ونهايته الاختياري.
- حاسبة سنوية حسب ذكرى العقد: تبدأ سنة الإيجار في اليوم والشهر المحددين، وتُختار سنة النهاية فقط. تحتسب كل سنة مرة واحدة، مع فصل المدفوع وغير المدفوع والإخلاء والمبالغ بلا تفاصيل سداد.
- إدخال العقود والفترات بأثر رجعي حتى خمس سنوات من تاريخ اليوم في عمّان، مع حفظ التاريخ الأصلي للسجلات السابقة.
- تقارير عربية لكل سوق، ولكل منطقة أو قسم، وتقرير شامل، بالصور ومعلومات العقد وسنوات الإيجار، مع العرض والطباعة وPDF.
- ربط واتساب ويب برمز QR باستخدام خدمة Connectra، وتنبيه انتهاء العقد قبل 90 يوماً إلى الرقم الأساسي +962770911991، مع أربعة مستلمين إضافيين كحد أقصى.
- سجل إرسال دائم لكل عقد ومستلم يمنع التكرار، وإعادة المحاولة للمستلمين الذين تعذر إرسال تنبيههم. الحالات غير المؤكدة تحتاج مراجعة قبل إعادة المحاولة.
- بحث باسم السوق أو الجهة المؤجرة، وفلترة بحسب المنطقة.
- تسجيل دخول محمي، وإنشاء حساب المدير من سطر الأوامر من دون كلمة مرور افتراضية مزروعة.


## تشغيل تنبيهات واتساب

اضبط `WHATSAPP_SERVICE_URL` و`WHATSAPP_API_KEY` في بيئة Laravel، واضبط نفس المفتاح في `WA_API_KEY` لخدمة `whatsapp-service`. استخدم جلسة مستقلة لهذا التطبيق.

```bash
cd whatsapp-service
npm ci --omit=dev --ignore-scripts
node server.js
```

افتح الإعدادات، اضغط «ربط / تحديث QR»، ثم امسح الرمز من الأجهزة المرتبطة في واتساب. الرقم الأساسي ثابت، ويمكن إضافة أربعة أرقام دولية أخرى وتفعيل التنبيهات أو إيقافها.

شغّل `php artisan schedule:run` كل دقيقة؛ يفحص النظام العقود كل ساعة بتوقيت عمّان. عند الربط المتأخر، يشمل العقود التي أصبحت داخل مهلة 90 يوماً ولم يصل تنبيهها بعد. للتحقق دون إرسال:

```bash
php artisan contracts:send-reminders --dry-run
```
